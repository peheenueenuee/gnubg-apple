### 操作を表示する条件

| 操作 | 表示する時 |
| --- | --- |
| ロール | 手番の人間プレイヤーがまだ振っておらず、未解決の申し出も処理中の作業もない時 |
| ダブル | エンジンがダブル可能と判定した人間の手番 |
| ヒント | 合法手があり、選択途中の移動がない人間の手番 |
| 投了 | 人間の手番でゲーム中、ダブルや投了の応答待ちではない時 |
| テイク／ドロップ、承諾／拒否 | その申し出への応答が必要な人間の手番 |
| 次のゲーム | ゲームが終わり、マッチは続く時 |
| 選択の取消／着手の確定 | 駒や手を選んでいる時／合法な一手が完成している時 |
| 上がり欄のボタン | 選択した駒を上げられる時。それ以外は個数のみ表示 |
| 評価／ロールアウト設定と開始 | 解析可能な人間の手番で、選択途中の手がない時 |
| 解析のキャンセル | 解析を実行中の時 |
| 新しいマッチ | エンジンが処理中でない時。色・ポイント数・対戦相手はそこから設定 |

処理中や応答待ちには空の合法手一覧と未使用の解析パネルも隠します。
解析結果と駒数などの情報は、該当する操作ボタンがなくても読めるように残します。

## 表示と操作の約束

- 盤面は常に自分の側を手前に表示し、盤面の数字は自分から見た座標です。
  合法手一覧の座標は、従来どおり「手番プレイヤー」から見た数字です。
- ダイスの「手番のダイス」と「直近のロール」を区別します。
  強制パスの場合も、実際に振った出目を履歴から取得します。
- 強調表示は直近の相手の着手を示し、新しいゲームではリセットします。
  手の選択中・ホバープレビュー中は、その表示を優先します。
- ホバーだけで着手は確定しません。一覧をクリックするか、盤面で選択後に
  「着手を確定」を押すと、エンジンが合法性を検証して着手します。
- 中央バーの駒は最大4個まで描き、合計個数を併記します。盤面の通常ポイントは
  最大4個を重ね、超過分は合計個数で表示します。駒はバーを含め32ポイント角で固定します。

## 検証と残件

- Cの回帰テスト：直近の着手と出目、強制パス、キューブ応答中の履歴保持、
  次ゲーム・新しいマッチでの履歴リセット。
- 日英のモデルテスト：ホバーによる状態の分離、選択途中の復元、白黒の切替、
  黒でのコンピューター戦、既存の対局・解析・キャンセル復帰。
- ビルド・署名・翻訳リソース検証。
- ログ：`.build/logs/interaction-*`。

この実行環境ではGUI登録に制限があるため、新しい表示の描画・余白・文字切れ・
実際のマウス操作は確認できていません。アプリを終了して開き直し、感想や追加の
要望を `要望.txt` に追記してください。
